Edge indices are local: 1 = +Y, 2 = −Y, 3 = +X, 4 = −X (PanelConnectivity.jl). Orientation aligned: halo index s → s; reversed: s → Nc+1−s. Panels 1–2: X→east, Y→north. Panels 4–5 are stored a quarter-turn rotated (X→south, Y→east) — the classic GEOS file-convention gotcha. Panels 3/6 are the polar caps.
